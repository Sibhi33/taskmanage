# Taskizmo

**Taskizmo** is a simple and efficient task management application designed to help users organize, prioritize, and track their daily tasks. With a clean interface and essential productivity features, Taskizmo makes it easy to stay focused and get things done.

## Features

- Create, update, and delete tasks  
- Organize tasks by categories or projects  
- Set deadlines and reminders  
- Mark tasks as completed  
- Responsive and user-friendly interface  

## Tech Stack

- React
- Vite
- Typescript
- TailwindCSS


## Components

### Home Page/Component
- Has Productivity quotes in the marquee
- A navbar for user-friendly navigation
- An image incorprated from unsplash
- The footer is the most interesting part , it indicates the date, day, Minutes left on the day of use, Days left in the year

### Tasks Page/Component
- Gallery view of tasks is given
- Each task their description, priority, status is seen here
- new tasks can be initiated using the plus button on the top right

### Add task Page/Component
- For a detailed additon of tasks
- Basically a form to add tasks
- Task status and priority can be modified as well as monitored here
